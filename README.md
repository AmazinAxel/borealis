# borealis

```fish
nix flake init -t github:AmazinAxel/borealis
```

Set `borealis.user` and add your `hardware-configuration.nix` and set `borealis.flake` to the path of your flake and then just run `nx-switch`

Make sure that your password hash is persisted!
